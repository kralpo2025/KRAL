# میوه‌برش 🍉🗡️

بازی برش میوه الهام‌گرفته از Fruit Ninja — کاملاً آفلاین، مخصوص موبایل (اندروید) با رابط فارسی.

## اجرا
فایل `index.html` را باز کنید (پیش‌نمایش داخل Anvex).

## امکانات
- برش با کشیدن انگشت (پشتیبانی از چند لمسی)
- نیمه‌شدن واقع‌گرایانه میوه‌ها با فیزیک، آبمیوه و ذرات
- بمب، امتیاز، کمبو (Combo)، جان، رکورد محلی
- افکت صوتی تولیدشده با Web Audio (بدون هیچ فایل خارجی)
- طراحی واکنش‌گرا و بهینه برای صفحه‌نمایش موبایل

## سورس
- `index.html` — ساختار اصلی
- `css/style.css` — استایل و رابط کاربری
- `js/game.js` — موتور بازی و فیزیک
- `js/fruits.js` — تعریف و رسم میوه‌ها
- `js/audio.js` — صداها
